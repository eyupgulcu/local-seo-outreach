# local-seo-outreach

Cold outreach for small local businesses built around a short, free visibility report. Covers picking a narrow vertical, selecting and vetting leads, running a no-paid-API mini audit per business, writing a one-page report with one biggest gap and one matching offer, drafting benefit-first first messages and follow-ups, and handing every send to a human for approval. Use when preparing outreach to local businesses, drafting cold emails or messages, or writing local SEO audit reports.

An agent skill in the Claude Code / Agent Skills format (`SKILL.md` with YAML frontmatter). Part of a small set of original skills: see [agent-skills](https://github.com/eyupgulcu/agent-skills) for the others.

## Install

```
git clone https://github.com/eyupgulcu/local-seo-outreach ~/.claude/skills/local-seo-outreach
```

On Windows, clone into `%USERPROFILE%\.claude\skills$n`. For a single project, clone into `<project>/.claude/skills/local-seo-outreach`. The skill loads when a task matches its description.
